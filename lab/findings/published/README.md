# Reviewed publication

Only deliberately sanitized Markdown/JSON extracts belong here. Raw results stay in ignored lab/runs/ or findings/evidence/. Never publish raw PCAPs, credential material, account databases or full private game state.

For each published artifact record source run/commit, redactions applied, reviewer/date and the private original's hash/reference. Sanitization must preserve enough detail to support the claim. This README is not evidence that any artifact passed review.
