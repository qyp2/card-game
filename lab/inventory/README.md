# Target inventory

Copy targets.example.json to an ignored targets.local.json and fill it after provisioning. It is a planning document; no runner consumes or enforces it yet. Never include passwords, tokens or private keys. credentialRef names an external secret source.

Record actual hostname/IP, instance ID, profile, commit, VM snapshot and allowed activities before a campaign. In the isolated profile verify adapters/routes after staging dependencies. Demo identities must be different and are excluded from active campaigns.

The example contains reserved names and sample addresses, not authorization to scan an existing machine. Scope redirects and every discovered endpoint explicitly.
